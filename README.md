# Gravoth

A dark fantasy action RPG for Android phones. These are test builds for friends.

## Install

1. Open **[Releases](https://github.com/petarzarkov/gravoth-releases/releases/latest)** on your phone and download `gravoth.apk` (about 135 MB).
2. Open the downloaded file. If Android asks, allow your browser or file manager to **install unknown apps**.
3. If Play Protect warns about an unknown developer, tap **More details → Install anyway**.

You need Android 8.0 or newer on a 64-bit phone (almost any phone from the last six years).

Every build is signed with the same key, so a newer release installs over the old one and keeps your characters.
